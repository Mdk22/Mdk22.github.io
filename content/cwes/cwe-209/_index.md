Within this archive, CWE-209 is assigned when a reproduced error response exposes sensitive information about the application environment, query logic, users, or associated data. A generic error alone is not sufficient; the public evidence must show the meaningful information disclosed and distinguish that disclosure from the primary weakness that caused the error.
