## Authorized Environments

All testing documented on this site was performed in authorized educational laboratories, deliberately vulnerable environments, or systems explicitly controlled for security training.

## Sensitive Information

Before publication, the following values are removed or redacted:

- Lab flags
- Session cookies
- Authorization tokens
- CSRF tokens
- API keys
- Passwords and credentials
- Personal information
- Reusable runtime secrets

Flags are represented using a redacted format such as `WEBVERSE{REDACTED}`.

## Evidence Integrity

Screenshots may be cropped or redacted to protect sensitive values, but their technical meaning is not altered.

Security conclusions are described only as strongly as the reproduced evidence supports.
