title: "Targeted Blind Byte Extraction"
weight: 190
purpose: "Recover a selected value by testing character positions through a previously verified Boolean oracle."
evidence_boundary: "Extraction is limited to the authorized target value, observed character range, request count, and explicit stop condition."
proves: "That the oracle can disclose the selected value incrementally when the recovered result is independently validated."
does_not_prove: "It does not establish unrestricted database access, modification capability, or compromise beyond the tested value."
